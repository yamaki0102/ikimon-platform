# IKIMON CREW

ikimon.life と IKIMON の活動を、年会費で支えてくれる方を募集しています。

大きな返礼を用意する制度ではありません。身近な自然を楽しむ人を増やし、写真・場所・時間・気づきの記録を残しやすくする。そのための開発と運用を続けるための、年会費制の応援枠です。

CREWとして参加いただいた方は、希望に応じて ikimon.life の CREW紹介ページでご紹介します。掲載は必須ではありません。個人名を出さず、社名や屋号だけにすることもできます。

## 会費

- 年額1万円（税抜）
- 年額3万円（税抜）
- 年額5万円（税抜）
- 年額10万円（税抜）

1万円、3万円、5万円の枠に、特典の違いはありません。限定コンテンツ、優先対応、割引はありません。応援したい金額で選んでください。

年額10万円のCREWには、希望する方へ WEBサイト制作・運用の返礼があります。WEBサイトが不要な方は、制作なしで参加できます。

## 会費を何に使うか

- ikimon.life の開発と運用
- 記録、地図、同定、学習ページの改善
- 写真、音、場所の記録を残しやすくする仕組み
- 地域や研究に使える観察レコードの整備
- 観察会、企業・自治体連携、学校利用へ広げるための準備

## WEBサイト制作の返礼

年額10万円のCREWには、希望する方へ WEBサイト制作・運用の返礼を用意しています。

HP 1サイトの制作と運用、月額運用費、軽微な更新対応、セキュリティアップデートまで含みます。いわゆる「作って終わり」ではなく、公開後に情報を直し続ける前提の返礼です。

## HP専用AIエージェント

WEBサイトを作る場合、修正依頼は LINE またはメールで受け付けます。24時間365日受付です。正月でも、夏休みでも、お知らせ追加、文言修正、営業時間変更、写真差し替えなどを送れます。

依頼内容は、HP専用のAIエージェントが受け取り、その時点で最もふさわしいAIを使って下書きや反映作業を進めます。基本的な更新は24時間以内を目安に対応します。

重たい変更、判断が難しい内容、公開前に人が確認すべき内容は、AIだけで進めません。八巻が確認し、必要に応じてたたき台を作ります。AIが処理できるもの、人が見るべきものを分けて運用します。

## セキュリティアップデート

WordPress や Movable Type などのCMSは便利ですが、放置すると危険です。管理画面、プラグイン、テーマ、古いPHPなどに弱点が残ると、そこを狙われることがあります。

狙われると、ページの改ざん、問い合わせフォームの悪用、迷惑メールの踏み台、検索結果での警告表示、復旧対応による営業機会の損失につながります。大げさに怖がる話ではありませんが、事業用のWEBサイトなら「古いまま放置」は経営リスクです。

CREW返礼で制作・運用するサイトでは、ミュトス級のAIが当たり前になる時代を前提に、CMSやサーバーまわりの弱点を定期的に見直します。

## ミュトスって何が怖いのか

Claude、ChatGPT、Gemini は、文章を書いたり調べものを手伝ったりするAIです。その中でも、ミュトスのような高度なAIは、WEBサイトやシステムの弱点を見つける力も上がっています。

これは「AIが悪い」という話ではありません。守る側もAIを使えます。ただ、弱点を見つける速度が上がるほど、古いCMSや放置されたプラグインは見つかりやすくなります。日本政府や海外の機関、企業も、AI時代のサイバーセキュリティを重要な課題として扱っています。

小さな会社やお店のサイトでも、他人事ではありません。サイトが止まる、信用を落とす、復旧費がかかる。そうなる前に、普段から更新できる状態にしておくことが大事です。

## こんな方におすすめ

- WordPress や Movable Type を使っているが、更新や保守をほとんどしていない
- ホームページの修正を業者に頼んでも、返事や反映が遅い
- お知らせ追加、営業時間変更、写真差し替えを気軽に頼める先がない
- 自社でAIを使うのは不安だが、AIで運用を速くする仕組みには関心がある
- 事業用サイトを、月額費を抑えながらきちんと持ちたい
- ikimon.life の活動も応援したい

## 返礼なしでも、応援してほしい理由

自然を楽しむ人が増えるほど、地域はもっと面白くなります。

記録する人が増えるほど、あとから見返せる地域の記憶が増えます。

ikimon.life は、その積み重ねを、教育、研究、地域活動、企業の自然共生活動へつなげるための場所です。大きな制度になる前の今から、支えてくれるCREWを募集しています。
