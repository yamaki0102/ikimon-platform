## (2) 文化財（静岡県・浜松市 オープンデータ CC BY 4.0・記念物）

### 参照した公式オープンデータ
1. **浜松市 指定等文化財一覧**（`shiteitoubunkazai.csv` / 静岡県オープンデータ `dataset/12010` / **CC BY**）
   - 全820件のうち記念物（史跡・名勝・天然記念物等）は **208件**（国指定7・県指定29・市指定115・**市認定57**）。
   - `公開情報 = '非公開'` の **3件** を除外 → **205件** を取り込み対象。
2. **静岡県 文化財一覧**（`220001_cultural_property.csv` / 静岡県オープンデータ `dataset/9558` / **CC BY**）
   - 全923件のうち記念物（史跡・名勝・天然記念物・特別史跡・特別名勝）は **273件**。
   - 浜松市データと重複する浜松市所在分・同一名称分（22件）を名寄せ除外 → **220件** を取り込み対象。

### 位置情報の扱い
- 静岡県・浜松市両CSVとも `緯度` / `経度` 列は全件空欄でした。
- 所在地の市区町村＋町字まで国土地理院（`msearch.gsi.go.jp`）で都道府県・市町村一致検証付き照合した **380件** に `gsi_address_match`（町字・大字レベル、`needsCoordinateReview = true`）、未一致 **45件**（+ MOE 24件 = 計69件）に市区町村代表点（`municipality_centroid`、`needsCoordinateReview = true`）を設定しています。全件 `verification_status = 'unverified'` として公開前の位置微修正対象が判別できます。
