## ZUKAN再利用の方針
既存 `Place / Entity / Source / Evidence / Claim / Rights / Review` で作品とモデル地点の根拠を管理し、企画時のみ `Program / Quest` を使用。スタンプは `docs/spec/zukan-product-architecture/PROFILE_HORIZON.md` に従う `mission_town_walk` の派生であり、新しいDB、認証、イベント管理基盤を作らない。既存 `platform_v2/src/services/{mapGuideSpots,guideUnlocks}.ts` の取得候補・安全条件・距離計算の適用可能性を先に評価する。

1. 作品名、原作漫画、アニメ版、シーズン、翻訳名の同一性を識別し、Wikidata QIDやメディア芸術データベースのIDを照合。MADBの[公開データセット](https://mediag.bunka.go.jp/madb_lab/lod/)で作品台帳の網羅性を拡大（利用規約・出典明記を遵守）。
2. 作品↔場所の関係を「確定モデル地／公式関連施設／舞台となる市町村／ファン報告のみ」に分類。原資料と訂正履歴を保持。市町村単位の記述からピンの精密座標を生成しない。
3. `Place` と別に安全な `visit_anchor` を現地実測。入口・公的広場・観光案内所を優先。建物内部・橋・狭い道路・神社・有料区域・営業中の施設では管理者同意と代替の一般公開地点を必須にする。
4. 個人用の記念スタンプは利用者操作による単発GPS精度検証または同意済みQR。GPS測位精度不十分なら保留・代替。高価な賞品は位置偽装・QR画像共有対策として運営者確認等の追加手段。バックグラウンド追跡不要。
5. サーバー側で企画ID+地点ID+参加者IDの冪等取得、期限、停止・非公開、安全閉鎖、許可取消、本人閲覧を確認。著作権保護されたキャラ画像・場面写真・ロゴ・グッズ賞品は別途許諾取得。
6. ZUKAN独自のチェックインを県のTIPS公式スタンプ・特典・提携と混同しない。公式キャンペーン参加権限は別契約。
