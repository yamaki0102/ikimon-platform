# Area Page Positive Feedback MVP

作成日: 2026-05-22
対象: `platform_v2` `/ja/map` のエリアサイドシート、および `/community/fields/:fieldId` への回遊

## 目的

エリアページを、単なる地域データ閲覧ではなく、投稿者が自分の記録を見返して気持ちよくなれる場所にする。

主成果は CVR ではなく、以下の3つ。

- 自己効力感: 自分の記録が、このエリアの見え方を少し進めたと分かる
- 集団効力感: みんなの視点が重なって、このエリアが育っていると分かる
- 回遊: 記録する前提ではなく、見返す、深掘る、細かいデータを見る導線で直帰を下げる

## 基本判断

投稿した人、または過去にそのエリアに関わった人を主対象にする。エリアページを見るタイミングは、現地で今すぐ投稿する場面よりも、帰宅後、移動中、通知やSNS経由で見返す場面を主想定にする。

ログイン済みで、そのエリアに自分の記録がある場合は、上部に以下の4ブロックを置く。

1. あなたの視点
2. あなたのおかげで
3. みんなの視点
4. 重なると見えること

未ログイン、または自分の記録がない場合は、以下に置き換える。

1. このエリアでよく見られている視点
2. みんなのおかげで育っていること
3. まだ足りない視点
4. 参加すると見えること

## 体験設計

件数ではなく、観察スタイルを返す。

- あなたはこのエリアで、植物の変化をよく拾っています。
- このエリアでは、あなたの目は足元の小さな変化に強いみたいです。
- あなたの記録は、写真つきの手がかりが多めです。

内部的には「植物ばかり」「鳥寄り」「環境写真寄り」のように茶目っ気を持って判定してよい。ただし表示文では、本人が笑われたと感じないように肯定的に言い換える。

「あなたのおかげで」は、実データで言える直接貢献だけを強く言う。

- あなたの3件で、このエリアの春の見え方が少し厚くなりました。
- 同じ場所を見返したことで、変化に気づける土台が育っています。
- あなたの写真で、あとから見返せる手がかりが増えています。

言わないこと:

- あなたのおかげで保全が進みました
- あなたの記録が政策を変えました
- 科学に大きく貢献しました

## みんなの視点

ランキングではなく、匿名・集計のゆるいつながりとして見せる。

- ほかの人は、鳥や昆虫の記録を多めに残しています。
- このエリアでは、写真つきの記録が少しずつ増えています。
- みんなの記録で、春と夏の顔が見え始めています。

比較は競争ではなく、「自分以外の視点もこの場所に重なっている」感覚を作るために使う。

## CTA 方針

主CTAは「記録する」ではなく、「見返す / 深掘る / 回遊する」にする。

ログイン済み:

1. 自分のこのエリアの記録を見る
2. みんなの視点を見る
3. エリア図鑑で詳しく見る

未ログイン:

1. エリア図鑑で詳しく見る
2. みんなの記録を見る
3. 自分の視点もここに重ねる

既存の「このエリアで観察会」は副導線に下げる。観察会作成は重く、見返し文脈の主導線ではない。

## MVP データ要件

`area-snapshot` に、ログインユーザーの `userId` を渡して以下を追加する。

- `viewerContribution`
- `communityPerspective`
- `overlapInsight`

MVPでは厳密な分類AIを作らず、既存列と名前ヒントで `plant / bird / insect / aquatic / fungi / habitat / audio / mixed` に粗く丸める。

## 表示位置

エリアシート内で完結する読ませ方を優先する。

推奨順:

1. ヒーロー写真
2. positive feedback 4ブロック
3. 自分 / みんなの代表記録カード
4. エリア図鑑、個別観察、自分の記録一覧へのリンク
5. 既存のギャラリー、季節タブ、努力量、希少種マスキング

ページ遷移は、興味が出た人の深掘りとして使う。最初から別ページへ飛ばして文脈を切らない。
