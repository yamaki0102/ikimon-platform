# Area Encyclopedia Album + Memory Spec - 2026-05-23

## Goal

エリア図鑑を、投稿フォームの前座ではなく `見て楽しむ / 思い出す` ための公開コンテンツにする。

対象は初見の一般閲覧者と、過去にその場所へ参加したログインユーザー。自然共生サイト、TSUNAG、公園、企業緑地、未認定の普通の場所を同じ型で魅力化する。

## Core Decisions

| 論点 | 決定 |
|---|---|
| 最上位ターゲット | 初見の一般閲覧者 |
| 主成功行動 | 見て楽しむ / 思い出す |
| ファーストビューの約束 | この場所では、今なにが見えるか |
| 主役素材 | 写真アルバム |
| 投稿0件の体験 | 見どころスターター + 季節アルバム予告 |
| 投稿増加後の体験 | 季節別アルバムへ育てる |
| 認定/TSUNAG | アルバム直下の信頼バッジ |
| 証拠/見守り | 下部の `見守り材料が育っている` |
| 最優先安全ルール | 公開/非公開境界を守る |

## Page Order

1. Place hero: 場所名、地域、今の季節、代表写真またはスターター。
2. Viewer memory strip: ログイン時だけ、本人がこの場所で残した記録を短く表示。
3. Public album: 公開可能な写真カードを `写真 + やさしい名前 + 日付/季節` で表示。
4. Trust badges: 公園、自然共生サイト、TSUNAG、保護区、管理者確認、一次情報確認状態。
5. Starter / next discovery: 投稿が薄い場合は `この場所で探したいもの` を出す。
6. Area watch: `見守り材料が育っている` として写真、季節、再訪、レビュー、effort の材料を表示。
7. Monitoring brief / claim boundary: 団体・企業向けの数字と、言えること/言えないことを下層に置く。

## Data Tiers

| Tier | 表示対象 | 共有 | 名前 | 位置 |
|---|---|---|---|---|
| `public_album_card` | 誰でも見える公開記録 | 可 | 和名または生活名 | 公開粒度 |
| `viewer_private_memory_card` | ログイン本人だけの記録 | 不可 | 段階的に丸める | 段階的に丸める |
| `restricted_public_card` | 公開はするが情報を丸める記録 | 可だが詳細控えめ | 生活名寄り | メッシュ/市町村 |
| `hidden_record_hint` | 主アルバムに出さない記録 | 不可 | 件数/理由のみ | 非表示 |

## Private Memory Rules

ログイン本人には、公開されない記録も `自分だけの思い出` として見せる。見た目は公開カードに近く、挙動は非公開にする。

必須表示:

- 鍵アイコン相当の `自分だけ` ラベル。
- `公開アルバムには出ていません` の明示。
- やさしい非公開理由を1つだけ。
- 共有導線なし。

非公開理由の例:

- `位置を守るため自分だけ表示`
- `人が写っているため公開していません`
- `くわしい確認が必要なため自分だけ表示`
- `公開設定により自分だけ表示`
- `大切な場所を守るため公開範囲を小さくしています`

段階的丸め:

- 希少種/精密位置: 生活名に寄せ、位置は広域または非表示。
- 人物/人声: 本人だけ表示、共有なし。
- レビュー未完: `くわしい確認が必要` と表示。
- 非公開設定: `公開設定により自分だけ表示` と表示。

## Starter Rules

投稿量が少ない場所は空白を出さない。

| データ量 | 主表示 |
|---:|---|
| 0 | 見どころスターター |
| 1-9 | 見つかったもの + 次に探したいもの |
| 10-49 | 今見えるもの |
| 50+ | 季節別アルバム |
| 100+ | 変化・見守り・報告可能性 |

スターターは `エリアタイプ + 地域 + 季節` から作る。周辺データを使う場合でも、この場所で確認済みとは表示しない。

## Acceptance Criteria

- 未ログイン閲覧者に本人限定カードが出ない。
- ログイン本人には、自分の非公開記録が `自分だけ` として出る。
- 非公開カードに共有リンク/SNS導線を出さない。
- 主アルバムは写真中心で、写真なし記録は下層扱いにする。
- `見守りメーター` という硬い主語を上部に出さず、下層で `見守り材料が育っている` と表示する。
- 自然の優劣を採点しているように見せない。
