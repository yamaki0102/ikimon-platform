# 公開ホーム状態分離 decision log

- 日付: 2026-07-23
- 状態: 採用
- 対象: ikimon.life public home

## 採用した判断

トップの責務を認証状態で分け、NodeとCloudflare Workerの間へ `state-split-v1` marker契約を置く。ログイン後は観察やモニタリングの実施を要求するダッシュボードではなく、普通の記録から返る意味を楽しむホームにする。

## 理由

従来は、Nodeの公開フィード、Workerの所有記録混在、presentation layerのゲスト向け文字列置換が重なり、実際の配信面で目的と責務が曖昧だった。状態別DOMと注入slotを正本化すると、セッション、データ不足、メディア種別、位置保護をサーバー側で一貫して扱える。

## 却下した案

- 同じ長いフィードをログイン状態で並べ替える
- 架空のおすすめやランキングでセクションを埋める
- トップ専用ナビと既存固定ランチャーを併置する
- 解析データがないときに空カードや説明用ダミーを出す
- NodeかWorkerの片方だけを変更する

## 影響

トップの旧focused-home、camera-first、UX copy rewriteは新契約でpass-throughとなる。他ページ、DB schema、解析pipeline、認証認可、公開位置契約には変更を加えない。
