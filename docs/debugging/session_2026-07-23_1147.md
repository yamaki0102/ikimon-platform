
## Phase 1: Error Message
staging の英語表示を 320px・CSS zoom 200% にすると、ページ全体が 18px 横にはみ出した。

## Phase 1: Reproduction

## Phase 1: Recent Changes
state-split home で、価値説明と位置保護に固定幅アイコン列を持つ2列 grid を追加した。既存テストは root の font-size 拡大だけを検証していた。

## Phase 2: Working Example
通常倍率と、既存の font-size 200% fixture では同じセクションが 320px に収まる。

## Phase 2: Difference Analysis
実効幅 160 CSS px では、固定アイコン列・gap・padding と英単語の min-content 幅の合計が残り幅を超える。実測では位置保護の子要素が x=338、価値説明が x=325 まで達した。

## Phase 3: Hypothesis
固定アイコン列そのものではなく、grid の `1fr` が既定の min-content 下限を持つため、実効幅 160 CSS px で列が縮み切らないことが根本原因と判断した。

## Phase 3: Verification Plan
英語・320px・CSS zoom 200% の回帰テストを先に追加し、変更前の bounding box と `scrollWidth` を採取する。

## Phase 4: Test Case
英語ホームへ `zoom: 2` を設定し、`documentElement.scrollWidth === clientWidth` を要求する E2E を追加した。修正前は 338 対 320 で失敗した。

## Phase 4: Fix Plan
home view の自動 grid track と、価値説明・位置保護の本文列を `minmax(0,1fr)` に変更する。本文へ `min-width:0` と `overflow-wrap:anywhere` を付け、狭幅時に min-content が親幅を押し広げないようにする。
