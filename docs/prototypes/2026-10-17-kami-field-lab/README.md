## 今回の要件と実装

1. **カメラと地図。** ユーザー操作でカメラを起動。GPSが許可されたときだけ実測位置と誤差円を表示し、地図上の現在位置に移動する。許可不可なら可美公園野球場の公表概略座標 `34.6858333,137.6938889` を初期表示と明示。地図はOpenStreetMapタイル + Leaflet（外部読込）。
2. **どこを向いたか。** `DeviceOrientationEvent`／対応端末のコンパス値を角度へ変換。推定60度の視野を地図上に扇形表示。未対応・較正不足時はスライダーで手動調整。GPS/方位/FOVは誤差があり、見た方向と写った物体の位置を同一視しない。
3. **画像の参考観察。** 撮影した画像だけを512px程度に縮小してCloudflare AI bindingへ送信し、`typesafe/jev-1.14.0` に樹木、草地、土・砂、水、鳥、昆虫の6種類の可視手掛かりを `noul` で質問。科・属・種の同定は行わず、未撮影・非検出を不存在・安全としない。AIの見解はReview済み記録に昇格させない。
4. **くり返し観察。** 手動撮影を標準。オプトインで60秒間隔・最大6回の自動画像判定（画面を閉じたら停止）。Worker側に既存Cloudflare native ratelimit binding（1分6回／Cloudflareロケーション単位）を追加。総利用額上限の保証ではないため、公開サービスへの直接統合前には利用量制御を見直す。
5. **「どれだけ見たか」。** GPS精度が100m以内かつ方角を取得した撮影だけを12分割した方向セクターに数える。重複方向は加算しない。これは**撮影方向の網羅**であり、生物の網羅、占有推定、発見率、調査完了ではない。
6. **音の記録。** 明示的なマイク操作で最大20秒録音。音種の認識はしない。録音結果は端末のIndexedDBに残し、再生・ファイル取得できる。
7. **記録の保全。** 写真・音声・撮影日時・端末位置・精度・方位・参考評価をブラウザのIndexedDBに保存。JSON（base64メディアを含む）で手動バックアップ可能。ZUKAN原本／R2／行政／一般公開への自動送信なし。画像解析時のみ縮小画像をJevへ送信。詳細位置は推論リクエストに含めない。
8. **権利・安全。** 球場の利用を妨げない。写り込む人物、車番号、未成年者などの扱いに注意。精密位置と録音内容を第三者公開しない。HTTPレスポンスはno-storeとnoindex。
