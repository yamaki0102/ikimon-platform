## 現在の動作

1. スマホの「観察を始める」を押すと、カメラ・GPS・方位を必要な範囲で許可して使用。地図はLeafletとOpenStreetMap。GPS許可前は野球場の概略地点と明示。GPSの精度円、方位の扇形は推定であり、真の観察範囲を保証しない。
2. **0.5秒ごとのローカル更新:** 小さなキャンバスを端末内で比較して映像の変化量と更新回数を表示する。0.5秒ごとの画像保存・Jev通信は行わない。カメラ映像自体はライブ。
3. **3モデル同時比較:** 初期設定では15秒間隔（30/60秒へ変更可能）。同じ1フレーム（幅384pxのJPEG）と7つの同じ質問（樹木・草・土・水・鳥・昆虫・クリケット）で、`typesafe/jev-1.14.0`、`@cf/cloudflare/clef-flash`、`@cf/cloudflare/clef-omni` をWorkers AI Binding経由で`Promise.all`同時実行。`Jev`は`assets.scene`、Clefは`images`へ同一バイト列を入力。判定は参考であり、種・属・科の確定や本人特定をしない。
4. **比較記録:** 一組の結果に時刻・JPEGのSHA256・方角/GPS文字列・3モデル別の返答確率、モデル識別子、応答時間、入力トークン、推定モデル料金、失敗状況を保存。実JPEG画像は保存しない。IndexedDB `zukan-three-model-comparisons-v1` / `observations`。JSONとCSVでエクスポート。CSVに方角とGPS表示内容も含む。
5. **現場の正解:** 比較記録ごとに「クリケットが実際に映っていた / 映っていなかった / 未確認」を後で指定できる。AIの一致率を正解率とは扱わない。別途ワンタップで「この場所でクリケットが行われていた」（人手の観察事実）を保存できるが、スポーツ活動の記録と一枚の写真への映り込みは別。
6. **音:** 「比較履歴・音」タブから端末マイクで最大20秒録音、端末内の元の音声レコードを保持。音の自動推論は**まだ未実装**。Clef-omniの音声比較は今後の独立検証へ。
